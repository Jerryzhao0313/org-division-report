# 2026-06-12

## 组织架构分工 HTML 变更（v3.26 → v3.27）

### 变更背景
将产品线负责人和人员产品线分配从硬编码改为从飞书备注字段动态解析。

### 具体变更

1. **processOrgData 新增 remark 字段**：`remark: f['备注']||''` 存储飞书备注字段

2. **新增 buildLeadOverrideFromRemarks()**：从所有员工的备注中解析产品线负责人标记，支持格式：
   - `产品线负责人：XX` / `负责：XX`
   - 多产品线用逗号/顿号分隔（如 `产品线负责人：PCB&仓库&工程、复合机器人`）
   - 自动去除"产品线"后缀（如 `非标集成线产品线` → `非标集成线`）

3. **删除 getAssignment 硬编码**：移除 `吴思豪→PCB&仓库&工程` 和 `欧阳雄军→PCB&仓库&工程` 两行

4. **三处 PL_LEAD_OVERRIDE 替换**：renderProductTableHtml / renderProductTree / renderReportView 中硬编码 `{'复合机器人':'欧阳雄军'}` 全部替换为 `buildLeadOverrideFromRemarks()`

5. **备注 tooltip 展示**：产品线表格和职能表格的角色列，有备注时 title 追加 `备注:xxx`

6. **showModal 备注行**：人员详情弹窗中新增备注行显示
