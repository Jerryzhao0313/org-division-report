# 2026-06-18 工作日志

## CI/CD 工作流搭建

- **目标**：为组织分工调整仓库（静态 HTML 汇报页）搭建 GitHub Actions 自动部署流水线
- **产出文件**：
  - `.github/workflows/deploy.yml` — 主工作流（validate → deploy 两阶段）
  - `scripts/deploy-to-cloudbase.js` — CloudBase 静态托管部署脚本
  - `CICD/架构分析.md` — 项目架构分析文档
  - `CICD/README.md` — 配置说明
  - `.gitignore` — Git 忽略规则（node_modules / 备份文件）
- **技术决策**：
  - 项目类型判定：纯静态 HTML，无构建工具，无 npm 依赖
  - Validate：html5validator (Python) 校验 HTML 语法
  - Deploy：@cloudbase/node-sdk 上传到 CloudBase 静态托管 /home/ 路径
  - 触发：push master → 校验+部署；PR → 仅校验
  - CloudBase 凭据放入 GitHub Secrets (`TCB_SECRET_ID` / `TCB_SECRET_KEY`)
- **待操作**：仓库当前无 GitHub 远程，需 `git remote add` 推送
